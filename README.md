# cmip7-first-look
Code and information relating to the CMIP7 first-look paper.

## Data access

CMIP7 data can be accessed via project [im55](https://my.nci.org.au/mancini/project/im55) (Australian models) and [ib12](https://my.nci.org.au/mancini/project/ib12) (all other models) on NCI.

The new naming system for variables in CMIP7 is explained in this [branded variables for CMIP7](https://wcrp-cmip.github.io/cmip7-guidance/docs/CMIP7/Branded_Variables/) documentation.
